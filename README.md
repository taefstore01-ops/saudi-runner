# سيف مان — SAiFMaN

لعبة جري ثلاثية الأبعاد عربية بأسلوب Pepsiman. تختار الشخصية (سيف أو سديم) والمنطقة
(الرياض، جدة، الدمام، مكة المكرمة، العلا، جازان)، ثم تجري وتجمع علب الطاقة وتتفادى العوائق.

- **التحكم:** الأسهم أو WASD (← → تغيير المسار، ↑ قفز، ↓ انزلاق). على الجوال: السحب بالإصبع.
- **التشغيل:** افتح `index.html` مباشرة (يحتاج إنترنت لتحميل Three.js والخطوط).

## الأدوات
- `tools/wrap_model.py` — يضغط شخصية GLB من Tripo ويحوّلها إلى `models/<id>.js`.
- `tools/make_regions.py` — يحوّل صور المناطق من Stitch إلى `art/regions.js`.
- `PROMPTS.md` — نصوص Tripo و Google Stitch.
